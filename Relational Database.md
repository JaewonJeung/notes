## Things to know
### SQL Joins
- Used to join different tables
- Costs major performance issue

### Indexes
- Ways of storing data for faster queries
- RDB supports many indexes. This allows you to optimize for different queries 
- Supports specialized indexing so that it supports stuff like GIS and full-text index

### RDBMS transactions
- Grouping multiple operations together atomically
- So for instance, if you want to a new post from a new user simultaneously, there's no possibility where a post exists without a user due to a user add error
