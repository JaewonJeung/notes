## When to use NoSQL DBs
- Flexible/Evolving data models
- Scalability (scaling horizontally)
- Handling big data (especially unstructured) / real-time web apps requiring data processing

! However, this doesn't mean that [[Relational Database]]s fail to do these either. Don't make broad statements but just discuss specific features

- Consistency model
    - Offers various consistency model, from strong consistency (all nodes have same data at the same time) to eventual consistency (BASE)
- Indexing. Supports indexes like RDB
